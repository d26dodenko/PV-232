## Реализованный модуль

В проект добавлен модуль `delivery.py` с функцией:

```python
calculate_delivery_cost(order_amount: float, distance_km: float, is_premium: bool) -> float
```

Функция рассчитывает стоимость доставки по сумме заказа, расстоянию и признаку premium-пользователя.

## Бизнес-правила

1. Если `order_amount < 0`, функция выбрасывает `ValueError`.
2. Если `distance_km < 0`, функция выбрасывает `ValueError`.
3. Если `order_amount >= 5000`, доставка бесплатна и равна `0.0`.
4. Если `order_amount < 5000` и `distance_km <= 5`, доставка стоит `200.0`.
5. Если `order_amount < 5000` и `5 < distance_km <= 20`, доставка стоит `500.0`.
6. Если `order_amount < 5000` и `distance_km > 20`, доставка стоит `500.0 + (distance_km - 20) * 30.0`.
7. Если `is_premium=True`, применяется скидка 50% на рассчитанную стоимость доставки.
8. Если доставка уже бесплатна, premium-скидка не меняет результат: `0.0`.

## Входные и выходные данные

| Параметр | Тип | Допустимые значения | Недопустимые значения |
| --- | --- | --- | --- |
| `order_amount` | `float` | `>= 0` | `< 0` |
| `distance_km` | `float` | `>= 0` | `< 0` |
| `is_premium` | `bool` | `True`, `False` | значения другого смысла не используются |

Выходной параметр: `float` — итоговая стоимость доставки.

Граничные значения:

- `order_amount`: `0`, `4999.99`, `5000`, значения больше `5000`;
- `distance_km`: `0`, `4.99`, `5`, `5.01`, `19.99`, `20`, `20.01`;
- отрицательные значения: `-0.01` для суммы заказа и расстояния.

## 3. ПРИМЕР - Исходный код

```python
# delivery.py

def calculate_delivery_cost(order_amount: float, distance_km: float, is_premium: bool) -> float:
    """
    Расчёт стоимости доставки.

    Бизнес-правила:
    1. Если order_amount < 0 или distance_km < 0 — ValueError.
    2. Если order_amount >= 5000 — доставка бесплатна (0).
    3. Иначе:
       - distance_km <= 5: 200
       - 5 < distance_km <= 20: 500
       - distance_km > 20: 500 + (distance_km - 20) * 30
    4. Для is_premium=True применяется скидка 50% на стоимость доставки.
    """
    if order_amount < 0:
        raise ValueError("order_amount must be >= 0")
    if distance_km < 0:
        raise ValueError("distance_km must be >= 0")

    if order_amount >= 5000:
        cost = 0.0
    elif distance_km <= 5:
        cost = 200.0
    elif distance_km <= 20:
        cost = 500.0
    else:
        cost = 500.0 + (distance_km - 20) * 30.0

    if is_premium:
        cost *= 0.5

    return cost
```

## 4. Реализация автотестов

```python
# test_delivery.py

import pytest
from delivery import calculate_delivery_cost


# test_delivery.py

import pytest
from delivery import calculate_delivery_cost


def test_free_delivery_from_5000():
    # Сумма 5000 — доставка бесплатная
    assert calculate_delivery_cost(5000, 10, False) == 0.0


def test_paid_delivery_below_5000():
    # Сумма 4999.99 — доставка платная
    assert calculate_delivery_cost(4999.99, 10, False) == 500.0


def test_short_distance():
    # До 5 км — тариф 200
    assert calculate_delivery_cost(1000, 5, False) == 200.0


def test_middle_distance():
    # От 5 до 20 км — тариф 500
    assert calculate_delivery_cost(1000, 20, False) == 500.0


def test_long_distance():
    # Больше 20 км — 500 + 30 за каждый км
    assert calculate_delivery_cost(1000, 30, False) == 800.0


def test_premium_discount():
    # Premium — скидка 50%
    assert calculate_delivery_cost(1000, 10, True) == 250.0


def test_negative_order_amount():
    # Отрицательная сумма — ошибка
    with pytest.raises(ValueError):
        calculate_delivery_cost(-1, 10, False)


def test_negative_distance():
    # Отрицательное расстояние — ошибка
    with pytest.raises(ValueError):
        calculate_delivery_cost(1000, -1, False)
```

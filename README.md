## 1. Проект на Python

Разработал [игру «Змейка»](snake/) на Python с использованием Pygame. В игре есть меню, пауза, перезапуск, выбор скорости, счёт и сохранение рекорда. Управление — стрелки или WASD. Игровую логику отделил от интерфейса, чтобы проверять её без создания окна.

Запуск из корня проекта:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r snake/requirements-dev.txt
cd snake
../.venv/bin/python -m snake_game
```

Enter — старт, Space — пауза, R — перезапуск, Esc — меню/выход. Скорость выбирается клавишами 1–3 в меню или на паузе.

## 5. Сторонний проект

Для сравнения взял [Conway’s Game of Life](https://github.com/laios42/Conway-s-Game-of-Life), версия `5c3c028921530fbb4b628e9689940d1f8a69a88f`. Программа моделирует клеточный автомат и состоит из двух файлов: `grid.py` и `main.py`. Исходники оставил без изменений.

При анализе проверил правила рождения и гибели клеток, устойчивую конфигурацию, осциллятор, границы поля и обработку мыши. Результат независимых проверок: **26 passed, 1 xfailed**. Ожидаемое падение связано с ошибкой клика, описанной в пункте 8. Покрытие этими проверками составило **100% строк и 97,5% ветвей**.

## 6. Размер программ

Размер измерил командой `radon raw`. **LOC** — все физические строки файла, **SLOC** — строки кода без пустых строк и отдельных комментариев. Для Snake учитывал только файлы `snake_game`, для Conway — `grid.py` и `main.py`. Тесты и документация в расчёт не входят.

Команда из корня проекта:

```sh
.venv/bin/python -m radon raw -s snake/snake_game
```

| Программа | LOC | SLOC |
|---|---:|---:|
| Snake | 469 | 408 |
| Conway’s Game of Life | 123 | 87 |

## 7. Цикломатическая сложность

Сложность измерил с помощью Radon:

```sh
.venv/bin/python -m radon cc -s snake/snake_game
```

Для функции `SnakeGame.turn` получил **V(G) = 5**. В ней четыре проверки: состояние игры, наличие ожидающего поворота, противоположное и текущее направление. Ручной расчёт: **V(G) = 4 + 1 = 5**.

Для `Grid.get_neighbours` в Conway получил **V(G) = 3**: два вложенных цикла дают **2 + 1 = 3**. Максимальная сложность метода в Snake — **8**, в Conway — **12**.

## 8. Дефектность

В Snake исправил замечание Ruff E501: строка превышала ограничение в 79 символов. После переноса строки проверка стиля прошла, все 47 тестов завершились успешно.

В Conway подтвердил ошибку обработки мыши: клик в точке **(100, 699)** вызывает `IndexError`. При высоте окна 700 и размере клетки 15 массив содержит 46 строк с индексами 0–45, а координата 699 даёт индекс 46. Для исправления нужно проверять границы индекса перед обращением к массиву.

Плотность подтверждённых функциональных дефектов Conway: **1 / (87 / 1000) = 11,49 дефекта на KLOC**, где размер взят в SLOC. Замечание к оформлению Snake в эту метрику не включал. Время реакции на баг-репорты не измерял.

## Вывод

Выполнил тестирование и сравнил размер, сложность и дефектность двух программ. Snake содержит больше кода из-за интерфейса и дополнительных возможностей, но разделение на модули упрощает её проверку и сопровождение. В Conway правила клеточного автомата прошли проверки, однако ошибка обработки мыши приводит к завершению программы. Этот пример показывает, что высокое покрытие само по себе не гарантирует надёжность.
